=========
Tutorials
=========

These tutorials build one small inference from scratch. As our example, we use the
global 21-cm signal: an absorption trough in the sky-averaged radio spectrum, measured
under a foreground thousands of times brighter. We emphasise that ``yabf`` is a very
general framework: it is not tied to any particular application or scientific field.
This example is merely representative and simple.

The tutorials are best read in order: the first defines the parameters, the second
builds the model from stages, and the third turns the model into a posterior and
samples it. Each one runs as it is shown here, and can also be read on its own.
